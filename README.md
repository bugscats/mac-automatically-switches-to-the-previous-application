# 上一个应用切换器

macOS（苹果桌面系统）原生常驻小工具：鼠标进入屏幕左侧中段，立即切回最近使用的上一个应用。移开再进入即可切回来。

面向轻量自用，使用系统原生菜单和设置窗口，无第三方运行依赖、无网络请求、无遥测。切换通过系统应用激活接口完成，不模拟键盘，也不需要辅助功能或屏幕录制权限。

## 功能与默认设置

- 默认触发区位于屏幕左侧正中，长 300 点、宽 5 点；高分屏上的“点”是界面逻辑尺寸。
- 移入一次只触发一次，停留不反复切换，按住鼠标按钮拖动时不触发。
- 默认每秒检查指针 120 次；可选 60 次节能模式。暂停时停止指针检查。
- 多屏默认启用各屏左侧外边缘，自动跳过与另一块屏幕相接的部分；可限制为主显示器。
- 菜单栏提供暂停、恢复、设置、登录后启动和退出。没有程序坞图标。
- 设置立即生效并保存在本机，更新安装时保留。
- 初次安装默认登录后启动；系统负责异常退出后的恢复。菜单退出会停止本次登录的后台任务，避免立即重新出现。下次是否自动运行取决于“登录后启动”开关；暂停状态也会保留。

## 安装或更新

需要 macOS 14 或更新版本，以及包含 Swift（原生编程语言）编译器的 Xcode Command Line Tools（系统命令行开发工具）、Python 3（脚本运行环境）。在终端执行：

```bash
xcode-select --install
```

已有开发工具时可跳过。克隆本仓库后进入项目目录：

```bash
git clone https://github.com/bugscats/mac-automatically-switches-to-the-previous-application.git
cd mac-automatically-switches-to-the-previous-application
bash install.sh
```

安装目标：

- 应用：`/Applications/切回上一个应用.app`
- 当前用户的登录启动项：`~/Library/LaunchAgents/local.taixu.previous-app-switcher.plist`
- 本机偏好标识：`local.taixu.previous-app-switcher`

安装器先构建并验证本地签名，然后备份旧应用与启动项，再替换文件。替换或启动失败时尝试恢复原状态，备份保留在项目的 `.build/` 目录。更新使用同一条安装命令。安装到系统应用目录需要当前用户具备写入权限，不自动提权。

若已有 CCCCorners（触发角工具）等软件接管左侧区域，先关闭重叠的左侧入口；其他触发角可继续使用。本工具独立工作。

编译器与 SDK（系统开发工具包）版本不匹配时，应选择与编译器匹配的已安装工具包。例如本次开发电脑使用：

```bash
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk bash install.sh
```

这个路径只适用于存在该工具包的电脑，不是通用安装前提。构建脚本默认使用系统开发工具选定的工具包。

## 使用

点击菜单栏回转箭头图标即可暂停或打开设置；暂停后图标变为暂停符号。再次打开 `/Applications/切回上一个应用.app` 也会显示设置。

设置包含区域长度、宽度、极速／节能模式和“仅在主显示器触发”。“重置区域与响应”恢复这些默认值，不改变暂停状态或登录启动开关。

启动后需要实际使用过至少两个应用，才能确定“上一个应用”。工具自己打开的菜单和设置不计入最近应用列表。

关闭“登录后启动”仅改变下一次登录行为，当前运行不受影响。需要停止当前运行时使用“暂停切换”或“退出”。退出后可重新打开应用，或执行下方的启动项重载命令恢复系统托管。

## 构建与测试

仅构建，不安装或更改登录启动项：

```bash
bash build.sh
bash tests/run.sh
```

产物位于 `.build/切回上一个应用.app`。区域测试覆盖单屏边界、共享边缘、错位屏幕、主屏限制和小屏裁剪；不依赖真实外接显示器。仓库的持续检查仅构建、验证区域逻辑和脚本语法，不操作桌面。

安装后可运行桌面行为测试；需要已安装 Google Chrome（谷歌浏览器）与 Visual Studio Code（代码编辑器），并保持默认区域、开启切换：

```bash
bash tests/run.sh --integration
```

该测试会移动真实鼠标、切换前台应用。运行期间暂停手动操作；测试驱动自身可能需要终端的辅助功能权限，这不是常驻工具的权限要求。它验证六次来回切换、焦点变化耗时以及区域内停留不反复切换。

## 卸载与恢复

停止本工具并把应用、登录启动项移入废纸篓，保留偏好与旧版备份：

```bash
bash uninstall.sh
```

重新安装即可恢复。若原来使用旧版脚本应用，首次迁移时会保存原版到 `~/Library/Application Support/TaixuPreviousAppSwitcher/original-applescript.app`；回退时先卸载原生版，再恢复备份并重新绑定原有触发工具。

手动重载登录启动项，可用于恢复当前会话的系统托管：

```bash
launchctl bootout "gui/$(id -u)/local.taixu.previous-app-switcher"
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/local.taixu.previous-app-switcher.plist"
```

若服务已退出，第一条提示找不到服务可以忽略；若登录启动已禁用，应先在菜单中重新开启，再重载。

## 验证范围与边界

已在一台苹果芯片电脑上验证普通窗口的双向切换、暂停、设置保存、启动项重载与异常恢复；也实际验证了失败安装恢复、卸载重装和强制重复打开仍仅保留一个实例。新增菜单后，最近一次协调鼠标操作的极速模式六次回归全部通过，系统前台焦点变化为 5～16 毫秒；节能模式六次为 8～20 毫秒。这些是本机样本，不包含显示器刷新与窗口绘制。

过程中曾观察到一次切换后焦点未保持，未能确定原因。后续诊断捕获了测试中指针移出的干扰样本，协调鼠标操作后整组通过。测试驱动会输出停留期间的应用序列和指针偏移；指针移出按测试环境受干扰处理，避免把人工操作当成程序故障。早期那次缺少诊断的样本无法回溯归因。

多屏共享边缘已通过坐标测试，真实多显示器、全屏应用、跨桌面、最小化窗口和其他系统版本仍待补测。一次激活请求是否切换桌面、恢复哪个窗口，由系统和目标应用决定。
